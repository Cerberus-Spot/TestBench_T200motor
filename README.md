# TestBench_T200motor
Caractérisation des moteurs T200 du sous-marin autonome de l'ASUQTR. Avec un capteur de distance HC-SR04, un Arduino UNO, et un drive ESC de bluerobotic, j'ai fait un petit programme pour enregistrer dans des fichiers csv la distance à intervalles réguliés parcourue par le moteur T200 sur le banc d'essaie.
